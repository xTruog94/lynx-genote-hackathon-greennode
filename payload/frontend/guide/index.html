1. Tổng quan giao diện Studio

Studio là vùng thao tác AI nằm bên phải màn hình chính, kết hợp với danh sách tài liệu và khung Chat.

Nguồn dữ liệu

Hệ thống hỗ trợ Tài liệu ngoài, Tài liệu nội bộ và Tài liệu cá nhân. Mỗi nguồn có bộ lọc phù hợp như lĩnh vực, cơ quan, ngày, nguồn cá nhân hoặc từ khóa.

Chọn tài liệu

Chọn một hoặc nhiều file để giới hạn ngữ cảnh cho Chat, So sánh, Quiz, Mindmap, Infographic và Đánh giá VBPL.

Trạng thái xử lý

Các tác vụ dài như tạo tài liệu, mindmap, infographic, so sánh hoặc đánh giá VBPL hiển thị tiến độ xử lý theo phần trăm và thông báo trạng thái.

2. Quy trình sử dụng chung

Hầu hết chức năng Studio đi theo cùng một quy trình: chọn nguồn, lọc tài liệu, chọn file, mở chức năng, nhập cấu hình và theo dõi kết quả.

  1. Chọn nguồn tài liệu: chuyển tab Tài liệu ngoài, Tài liệu nội bộ hoặc Tài liệu cá nhân.
  2. Lọc và tìm kiếm: nhập từ khóa, chọn lĩnh vực/cơ quan/ngày/nguồn để thu hẹp danh sách.
  3. Chọn file: tick một hoặc nhiều tài liệu cần dùng làm ngữ cảnh.
  4. Mở Studio: bấm thẻ chức năng tương ứng trong panel Studio.
  5. Nhập cấu hình: điền hướng dẫn bổ sung, template, mức độ, số câu, khối nội bộ hoặc file mẫu tùy chức năng.
  6. Chạy và kiểm tra kết quả: theo dõi tiến độ, xem kết quả, tải file đầu ra hoặc tiếp tục hỏi đáp.
Lưu ý bảo mật: Không nhập thông tin mật, thông tin khách hàng, dữ liệu nhạy cảm hoặc nội dung chưa được phép chia sẻ vào Web Search hoặc các prompt mở rộng nếu chính sách đơn vị không cho phép.
👁

3. Preview file

Xem nhanh file PDF, DOCX, TXT, Markdown, ảnh và các định dạng phổ biến trong nguồn hiện tại.

  1. Bấm thẻ Preview file trong Studio.
  2. Dùng ô tìm kiếm, bộ lọc nguồn hoặc loại file để tìm tài liệu cần xem.
  3. Bấm vào một file để xem preview. Với PDF/ảnh, hệ thống tải bản xem trước; với text/Markdown, nội dung hiển thị trực tiếp.
  4. Nếu đang chọn một file ở danh sách chính, Preview có thể mở trực tiếp vào file đó để kiểm tra nhanh.
💬

4. Chat với tài liệu

Hỏi đáp, tóm tắt và khai thác thông tin dựa trên tài liệu đã chọn hoặc phạm vi nguồn/bộ lọc hiện tại.

  1. Chọn nguồn dữ liệu và tài liệu cần hỏi đáp. Có thể chọn nhiều file để mở rộng phạm vi trả lời.
  2. Bấm Chat trong Studio nếu chưa ở chế độ Chat.
  3. Nhập câu hỏi vào thanh nhập cuối khung Chat hoặc dùng micro nếu được hỗ trợ.
  4. Bấm Gửi và đọc câu trả lời streaming theo thời gian thực.
  5. Hỏi tiếp để làm rõ, yêu cầu tóm tắt, lập bảng, trích dẫn, so sánh nội dung trong cùng nhóm tài liệu.
Gợi ý prompt: “Tóm tắt 5 điểm chính”, “Liệt kê điều khoản liên quan đến trách nhiệm của đơn vị”, “Trích dẫn đoạn văn bản làm căn cứ cho câu trả lời”.

5. Web Search trong Chat

Tra cứu thông tin mới ngoài kho tài liệu khi cần cập nhật bối cảnh bên ngoài.

  1. Bấm Chat trong Studio.
  2. Ở thanh nhập cuối màn hình, bấm nút Web Search có biểu tượng quả địa cầu.
  3. Khi bật, nút chuyển màu nổi bật và hiển thị thông báo đang bật.
  4. Nhập câu hỏi cần tra cứu web rồi bấm Gửi.
  5. Bấm lại Web Search để tắt và quay về hỏi đáp theo tài liệu/nguồn đang chọn.
Khuyến cáo: Chỉ dùng Web Search cho thông tin công khai. Không nhập dữ liệu mật, dữ liệu khách hàng hoặc nội dung nội bộ chưa được phép công bố.

6. So sánh tài liệu

Đối chiếu tài liệu nguồn với tài liệu ở kho nội bộ, bên ngoài hoặc cá nhân theo luồng 3 bước.

  1. Bước 1 - Chọn tài liệu nguồn: chọn một hoặc nhiều tài liệu đang cần đối chiếu trước khi mở So sánh.
  2. Bấm thẻ So sánh trong Studio.
  3. Bước 2 - Chọn kho đối chiếu: chọn Tài liệu nội bộ, Tài liệu ngoài hoặc Tài liệu cá nhân. Dùng bộ lọc lĩnh vực, cơ quan, ngày, nguồn hoặc từ khóa nếu cần.
  4. Chọn một hoặc nhiều tài liệu đích để so sánh.
  5. Bước 3 - Rà soát: kiểm tra số tài liệu nguồn, số tài liệu đối chiếu, bộ lọc đang áp dụng.
  6. Nhập Hướng dẫn so sánh để AI tập trung vào phạm vi áp dụng, định nghĩa, nghĩa vụ, ngoại lệ, viện dẫn hoặc tác động liên điều/khoản.
  7. Bấm Bắt đầu so sánh và chờ kết quả gồm điểm giống/khác, evidence và nhận xét tổng hợp.

7. Đánh giá VBPL

So sánh song song tài liệu đã chọn với từng khối trong kho văn bản nội bộ và tạo file Excel kết quả.

Điều kiện truy cập: Người dùng cần nhập đúng token Đánh giá VBPL được cấu hình bởi quản trị hệ thống trước khi dùng chức năng.
  1. Chọn một hoặc nhiều tài liệu nguồn cần đánh giá.
  2. Bấm Đánh giá VBPL trong Studio.
  3. Nhập token truy cập và bấm Tiếp tục.
  4. Chọn các khối nội bộ cần đối chiếu hoặc bấm Chọn hết.
  5. Nhập Hướng dẫn bổ sung nếu muốn tập trung vào tác động nghiệp vụ, văn bản nội bộ cần sửa đổi hoặc đơn vị đầu mối.
  6. Bấm Bắt đầu đánh giá VBPL và theo dõi tiến độ từng khối.
  7. Tải file Excel của từng khối hoặc bấm Tổng hợp để merge kết quả.
  8. Có thể upload lại file Excel kết quả đã chỉnh sửa vào kho kết quả đánh giá nếu quy trình yêu cầu.

8. Tạo và chia sẻ Quiz

Sinh bộ câu hỏi từ tài liệu, lưu vào kho quiz cá nhân, chia sẻ cho user khác và xem kết quả làm bài.

  1. Chọn tài liệu làm ngân hàng kiến thức.
  2. Bấm Tạo quiz trong Studio.
  3. Nhập Tiêu đề quiz, chọn Số lượng câu hỏi từ 1 đến 20 và thời gian làm bài. Nhập 0 nếu không giới hạn thời gian.
  4. Chọn Mức độ: Dễ, Trung bình hoặc Khó.
  5. Chọn ít nhất một Loại câu hỏi: Trắc nghiệm, Đúng/Sai hoặc Tự luận ngắn.
  6. Nhập Yêu cầu thêm cho AI để ưu tiên nội dung, định nghĩa, điều kiện áp dụng hoặc nghĩa vụ tuân thủ.
  7. Bấm Tạo quiz. Sau khi sinh xong, làm thử, lưu hoặc mở trong kho quiz.
  8. Trong Kho Quiz, chủ sở hữu có thể sửa, xóa, xem bảng xếp hạng, chia sẻ quiz cho user khác bằng cách nhập username và cập nhật danh sách.
  9. Với quiz được chia sẻ, người nhận bấm Bắt đầu trước khi làm bài. Nếu quiz có thời gian, hệ thống hiển thị đếm ngược và có thể tự nộp khi hết giờ.

9. Tạo tài liệu theo skill/sample

Tạo tài liệu đầu ra dựa trên file skill và file sample output trong Tài liệu cá nhân.

File skill là gì?

File mô tả yêu cầu, quy tắc nghiệp vụ, cấu trúc nội dung, tiêu chí viết hoặc chỉ dẫn mà AI cần tuân thủ khi tạo tài liệu.

File sample output là gì?

File mẫu đầu ra chuẩn để AI bám theo định dạng, văn phong, bố cục, cách trình bày bảng biểu và mức độ chi tiết.

  1. Upload sẵn file skill và file sample output vào Tài liệu cá nhân.
  2. Bấm Tạo tài liệu trong Studio.
  3. Ở cột Chọn file skill, chọn một hoặc nhiều file mô tả yêu cầu/quy tắc.
  4. Ở cột Chọn file sample output, chọn đúng một file mẫu đầu ra.
  5. Dùng bộ lọc nguồn hoặc tìm kiếm trong từng cột nếu danh sách file dài.
  6. Nhập Hướng dẫn bổ sung, ví dụ: “ưu tiên văn phong trang trọng”, “giữ đúng cấu trúc sample”, “bổ sung bảng use case”.
  7. Bấm Tạo tài liệu và theo dõi tiến độ xử lý nền.
  8. Kiểm tra nội dung sinh ra trong phiên Chat/kết quả liên quan trước khi tải xuống hoặc sử dụng tiếp.

10. Tạo Mindmap

Tạo sơ đồ tư duy Markmap từ tài liệu đang chọn, hỗ trợ xem preview, copy Markdown, mở hoặc tải HTML.

  1. Chọn ít nhất một file ở kho tài liệu.
  2. Bấm Tạo mindmap trong Studio.
  3. Nhập Chủ đề trung tâm nếu muốn cố định chủ đề chính; có thể để trống để AI tự xác định.
  4. Chọn Độ sâu tối đa từ 2 đến 5 cấp.
  5. Chọn Mức chi tiết: Ngắn, Cân bằng hoặc Chi tiết.
  6. Nhập Hướng dẫn bổ sung nếu muốn gom nhóm theo quy trình nghiệp vụ, phòng ban, rủi ro, kiểm soát hoặc ý chính cần nhấn mạnh.
  7. Bấm Tạo mindmap, chờ hệ thống tạo Markmap và xem preview.
  8. Sau khi có kết quả, có thể Copy Markdown, Mở HTML hoặc Download HTML.

11. Tạo Infographic PNG

Trực quan hóa nội dung tài liệu hoặc prompt thành ảnh infographic PNG theo template nội bộ.

  1. Chọn file nếu muốn tạo infographic từ tài liệu; hoặc chuẩn bị prompt/chủ đề nếu tạo không dùng file.
  2. Bấm Tạo infographic trong Studio.
  3. Nhập Chủ đề nếu muốn cố định thông điệp chính.
  4. Bật Dùng nội dung file đang chọn để lấy ngữ cảnh từ tài liệu; tắt lựa chọn này nếu muốn tạo chỉ từ prompt trong ô Hướng dẫn bổ sung.
  5. Chọn Layout mẫu: Auto template, Executive dashboard, Risk matrix, Process flow, Roadmap timeline, Comparison matrix, Document summary hoặc KPI scorecard.
  6. Chọn Tone: Chuyên nghiệp, Lãnh đạo, Hiện đại hoặc Tập trung rủi ro.
  7. Chọn Ngôn ngữ: Tiếng Việt hoặc English.
  8. Nhập Hướng dẫn bổ sung để nhấn mạnh KPI, rủi ro, kế hoạch xử lý, thông điệp lãnh đạo hoặc phong cách trình bày.
  9. Bấm Tạo infographic. Sau khi hoàn tất, xem ảnh và bấm Download PNG hoặc mở ảnh.
Điều kiện khi không dùng file: Cần nhập chủ đề hoặc hướng dẫn đủ cụ thể, tối thiểu khoảng 20 ký tự để hệ thống có đủ thông tin tạo infographic.

12. Tải audio/video tạo transcript

Upload file WAV, MP3 hoặc MP4 có âm thanh để hệ thống tự động tạo transcript.

  1. Bấm Tải audio/video trong Studio.
  2. Bật hoặc tắt Hiệu chỉnh bằng AI. Khi bật, hệ thống cố gắng sửa chính tả, dấu câu và xuống dòng cho dễ đọc.
  3. Bấm Chọn file và chọn file WAV, MP3 hoặc MP4 có âm thanh rõ.
  4. Chờ hệ thống xử lý, trích xuất âm thanh nếu là MP4 và tạo transcript.
  5. Kiểm tra transcript trong kết quả/phiên làm việc sau khi hoàn tất.

13. Tạo video từ PPTX

Upload file PowerPoint và chọn giọng đọc để tạo video thuyết trình có TTS từng slide.

  1. Bấm Tạo video trong Studio.
  2. Bấm Chọn file PPTX và chọn file PowerPoint định dạng .pptx.
  3. Chọn giọng đọc Nam hoặc Nữ.
  4. Bấm Bắt đầu tạo video.
  5. Theo dõi trạng thái xử lý trên thẻ Studio/khung Chat. Khi hoàn tất, tải video theo đường dẫn kết quả nếu có.

14. Graph View

Xem mạng liên kết tài liệu theo nguồn, nhóm tài liệu và độ tương đồng tiêu đề/nội dung.

  1. Bấm Graph View trong Studio.
  2. Hệ thống mở màn hình mạng liên kết tài liệu theo nguồn hiện tại.
  3. Dùng chuột để kéo graph, kéo node, zoom in/out hoặc chọn node cần xem chi tiết.
  4. Quan sát loại quan hệ: cùng nhóm, cùng lĩnh vực pháp lý hoặc giống nội dung. Đường nét đứt có thể biểu thị mức tương đồng thấp hơn.
  5. Nếu đã chọn tài liệu trước đó, graph có thể focus vào node tương ứng để dễ theo dõi ngữ cảnh.
  6. Bấm node để xem thông tin và mở Preview file nếu cần.

15. Tạo slide bằng Presenton

Mở công cụ Presenton ở tab mới để tạo hoặc chỉnh sửa bộ slide thuyết trình.

  1. Bấm Tạo slide trong Studio.
  2. Hệ thống mở Presenton ở tab mới nếu URL đã được cấu hình.
  3. Tạo hoặc chỉnh sửa bộ slide thuyết trình trên Presenton theo nhu cầu.
  4. Nếu xuất hiện thông báo chưa cấu hình URL, liên hệ kỹ thuật hoặc kiểm tra biến môi trường Presenton.

16. Lưu ý, bảo mật và xử lý lỗi thường gặp

Thực hành tốt

  • Chọn đúng nguồn dữ liệu trước khi thao tác để AI lấy ngữ cảnh chính xác.
  • Chỉ chọn các file thật sự cần thiết để giảm nhiễu và tăng chất lượng kết quả.
  • Viết hướng dẫn bổ sung cụ thể: mục tiêu, tiêu chí, định dạng đầu ra, phạm vi cần tập trung.
  • Kiểm tra lại kết quả AI trước khi dùng trong báo cáo, đào tạo hoặc quy trình nghiệp vụ.

Bảo mật dữ liệu

  • Không đưa dữ liệu mật hoặc thông tin khách hàng vào Web Search.
  • Không chia sẻ quiz/tài liệu cho user không thuộc phạm vi được phép.
  • Với Đánh giá VBPL, bảo quản token theo quy định và không gửi token qua kênh không an toàn.
  • Tải xuống và lưu trữ file kết quả theo đúng quy định nội bộ.
